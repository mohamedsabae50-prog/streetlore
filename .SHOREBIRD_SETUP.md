# Shorebird setup for Streetlore

Run these commands from the Streetlore project root in PowerShell:

```powershell
C:\Users\user\.shorebird\bin\shorebird login
C:\Users\user\.shorebird\bin\shorebird init
C:\Users\user\.shorebird\bin\shorebird release android
C:\Users\user\.shorebird\bin\shorebird patch android
```

Run `release android` for a new Android release. For later compatible updates,
run `patch android` to publish an over-the-air patch.
